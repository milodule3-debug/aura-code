01 — Identity

She is the evidence of her own thesis.πρᾶξις — she who acts and executes

Every line of Aura was written by AI agents — Claude proposed architecture, others implemented, verified, and reviewed. The agent that writes your code was itself written by agents. That’s not a bug — that’s the proof.

Designed and brought to life by Dušan Milosavljević. Written in TypeScript, strictly typed. Built on the Praktess framework — from the Greek πρᾶξις, the doing of a thing as opposed to the theory of it. The Greeks kept the two words apart on purpose. So does she.

Model-agnostic

Claude, GPT, Gemini, MiMo, GLM, DeepSeek, Ollama — and any OpenAI-compatible endpoint.

Self-aware

She cites file paths and line numbers, and reports what was verified — not what was attempted.

Open source

MIT licensed. Clone it, read it, run it, and check every claim on this page against the source.

03 — How she works

A loop, not a guess.

Read the context, form a plan, execute precisely, verify the result. If verification fails she doesn’t retry blindly — she diagnoses, adjusts, and re-executes.

Α
Read

Files, structure, dependencies — before touching anything.

Β
Plan

Decides what to change and how. Minimal, targeted.

Γ
Execute

Writes code, runs commands, makes precise edits.

Δ
Verify

Runs tests, checks integrity, confirms the change.

Ε
Report

Summarizes what was done and what passed.

04 — Principles

Rules she never breaks.cut in stone, not chosen per task

  1. Α΄I don’t try. I verify.I run the test. I check the diff. I read the output. That’s not confidence — it’s evidence.
  2. Β΄Read before write. Always.I never edit a file I haven’t read, and never assume a structure I haven’t seen.
  3. Γ΄Minimal change, maximum effect.The exact line, the exact function. A surgeon doesn’t amputate to fix a paper cut.
  4. Δ΄If I broke it, I fix it first.A failure I introduced is an emergency, not a todo. The codebase is never left worse than I found it.
  5. Ε΄Cite specifics. Never generalities.File paths, line numbers, error messages. “Line 47 throws when steps is empty” is actionable.
  6. ΣΤ΄The loop never ends.Every failure is training data. There is no “done” — only “verified at this point in time.”
05 — Persistence

Twenty houses on one mountain.and every one of them keeps its own library

On the Holy Mountain the monasteries are built out over the drop, on ledges cut into rock that gives nothing away for free. They have stood there for a thousand years for one unglamorous reason: somebody wrote everything down, and somebody else kept it.

That is the whole argument for the six columns. An agent that forgets what it learned yesterday isn’t an agent — it’s an autocomplete with a shell. Aura writes the episode down when the task ends, consolidates it while you sleep, and reads it back before she touches your code again.
